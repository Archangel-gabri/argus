# Argus

Личный командный центр для своих машин, денег, подписок и ИИ-доступов. Один десктоп, всё локально,
ничего в облаке.

Версия 0.1.0 · для одного человека · в активной разработке · собирается в AppImage для Linux.
Каталог проекта называется `Nexus-One` по историческим причинам — приложение называется Argus.

---

## Зачем оно

У человека, который держит свои серверы, копятся разрозненные вещи: SSH-доступы в конфиге,
подписки в письмах, остатки в приложениях банков, ключи ИИ в переменных окружения. Каждая по
отдельности живёт нормально, а вместе не отвечает на простые вопросы: сколько уходит в месяц,
какая нода не отвечает прямо сейчас, где лежит ключ от этой биржи, за что списали вчера.

Argus не заменяет ни банк, ни Termius, ни панель хостера. Он собирает **обзор и частые действия**
в одно окно — и, в отличие от дашборда, умеет нажимать кнопки: подключиться, перезагрузить,
разбудить, скопировать ключ.

Три вещи, которые определяют всё остальное:

- **Один пользователь и его собственный парк.** Не управление чужой инфраструктурой как услуга.
- **Local-first.** Данные лежат в зашифрованном файле на этой машине. Никакого своего облака.
- **Заполняет человек.** Внутри нет никаких LLM: приложение не додумывает данные за владельца.

## Что умеет

**Парк и SSH.** Устройства заводятся руками или импортом `~/.ssh/config`, находятся через
Tailscale. Терминал, передача файлов, проброс портов, прыжок через бастион, закрепление ключа
хоста при первом подключении. Метрики с историей, список открытых портов, инвентарь железа.
Питание, Wake-on-LAN и выбор системы у машин с двумя ОС.

**Экран машины.** Отдельное окно. Основной путь — свой агент, который ставится на целевую машину;
для Windows есть запасной путь через RDP. Подробности протокола — в [`agent/README.md`](agent/README.md).

**Финансы.** Счета и остатки вносятся руками. Биржи с ключом «только чтение» отдают остаток сами,
Т-Инвестиции — по токену, адреса в блокчейне читаются через публичные узлы. У Т-Банка — вход в
кабинет внутри приложения; выписки оттуда не парсятся, это решение принято осознанно.

**Подписки.** Суммы, валюты, периоды, даты продления. Платёж за сервер связывается с самим
сервером, чтобы одна трата не считалась дважды. Автоматического поиска подписок по почте нет.

**ИИ-доступы.** Реестр аккаунтов, каналов и ключей: где что лежит, что чем оплачено, чем
заменить. Расход считается по локальным журналам инструментов; квоты берутся у тех провайдеров,
которые их отдают.

## Чего он не делает намеренно

- Не хранит ничего в облаке и не синхронизируется между устройствами.
- Не содержит LLM и не заполняет поля за человека.
- Не парсит банковские выписки и не притворяется бухгалтерией.
- Не управляет чужими серверами и не работает как многопользовательский сервис.

## Как это устроено

```
src/main/       процесс с полномочиями: хранилище, SSH, сеть, IPC. Только здесь есть секреты.
src/preload/    мост между процессами. Через него не проходит ни один секрет.
src/renderer/   интерфейс: React, Tailwind, Zustand.
src/shared/     то, что нужно обеим сторонам: формат денег, разбор дат, опознание компаний.
agent/          агент трансляции экрана на Go, ставится на целевую машину.
resources/      собранные бинари агента и вшитый каталог цен на модели.
tools/          инструменты разработки: осмотр интерфейса, проверка доступности, логотипы.
docs/           решения, планы и разборы. Архивные помечены прямо в заголовке.
e2e/            проверки на собранном приложении.
```

Данные лежат в зашифрованной базе (SQLCipher) в каталоге приложения. Ключ выводится из
мастер-пароля, который знает только владелец: **восстановления нет**. Секреты живут исключительно
в процессе с полномочиями — интерфейс получает признаки «ключ заведён», но не сам ключ.

## Сборка и запуск

```bash
npm install
npm run dev          # запустить в разработке
npm run check        # полная проверка: типы, стиль, тесты, сборка
npm run dist         # собрать AppImage в dist/
```

Отдельные проверки:

```bash
npm test             # быстрые проверки
npm run test:vault   # хранилище на настоящем файле (нужен ABI Electron)
npm run test:agent   # агент: gofmt, vet, go test -race
npx playwright test  # сквозные на собранном приложении
node tools/user-walk.mjs   # проход интерфейса кликами, как человек
node tools/a11y-lab.mjs    # проверка доступности движком axe-core
node tools/ui-lab.mjs      # снимки экранов и поиск обрезанного текста
```

Установить собранный образ себе:

```bash
npm run dist
cp dist/Argus-0.1.0.AppImage ~/Applications/.Argus.new
chmod +x ~/Applications/.Argus.new
mv -f ~/Applications/.Argus.new ~/Applications/Argus.AppImage
```

Переименование атомарно, поэтому запущенная копия доживёт до перезапуска. После установки
приложение надо перезапустить — само оно новую сборку не подхватит.
