# Дизайн-система Argus

> Самодостаточное описание: по нему собирается экран, неотличимый от остальных.
> Всё ниже — не пожелания, а то, что уже стоит в коде
> (`src/renderer/src/assets/main.css`, `components/ui/Page.tsx`, `DESIGN.md`).
> Правишь дизайн — правь и этот файл, иначе он начнёт врать.

---

## 1. Что это и для кого

Личный командный центр одного человека: серверы, деньги, подписки, устройства, ИИ. Владелец —
технический power-user, единственный пользователь. Данные лежат локально, в облаке нет ничего.

**Заходят сюда посреди работы, на десять-двадцать секунд**, с одним вопросом: «всё ли цело и
сколько у меня осталось». Не изучать, не анализировать — свериться. Отсюда следует всё остальное.

Настроение: **тихий пост наблюдения**. Спокойный контроль, тепло и дорого. Не «дашборд стартапа»,
не витрина, не отчёт.

## 2. Палитра — Graphite & Ember

| Токен | Значение | Роль |
|---|---|---|
| `bg` | `#121110` | фон приложения |
| `surface` | `#1a1816` | боковая панель, рейки |
| `card` | `#201d1a` | карточки (обычно `bg-card/60`) |
| `card-hover` | `#262220` | наведение |
| `border` | `#2a2622` | все волосяные линии |
| `accent` | `#f59e0b` | ember |
| `accent-hover` | `#d97706` | наведение на акцент |
| `glow` | `rgba(245,158,11,.14)` | свечение живого |

Текст: заголовки `white`, основной `stone-300 #d6d3d1`, подписи `stone-400 #a8a29e`,
служебное `stone-500 #78716c`. Классы `slate-*` в проекте ремапнуты на тёплые `stone` —
не путаться: визуально это тёплый графит, а не синий.

**Дисциплина акцента.** Янтарь допустим ровно в четырёх местах: главная кнопка действия, активный
пункт навигации, ссылка, полоса прогресса. Больше нигде. Если янтарного на экране больше четырёх
пятен — экран сломан, потому что цвет перестал что-либо значить.

## 3. Типографика

Inter Variable. Одна гарнитура на всё; моноширинный — только для IP-адресов, путей, терминала и
адресов кошельков, то есть для того, что копируют, а не читают.

| Роль | Размер / вес |
|---|---|
| Заголовок экрана | 24px / 600, `white` |
| Подзаголовок экрана | 14px / 400, `stone-500` |
| Заголовок секции | 13–14px / 600 |
| Число-якорь | 22–26px / 600, `tabular-nums` |
| Основной текст | 13–14px / 400 |
| Подпись, единица | 11–12px / 400, `stone-500` |
| Айбрау (капс) | 10–11px / 500, трекинг `.13em`, `stone-500` |

**`tabular-nums` на каждом числе без исключений** — иначе колонки цифр пляшут.

Айбрау-капсом — не больше двух-трёх на экран. Когда каплоком кричит всё, не слышно ничего.

## 4. Физика

**Слои, а не тени.** Глубина делается разницей фона (`bg` → `surface` → `card`) и волосяной
границей `border`, а не размытыми тенями. Тень в этой системе — признак чужого компонента.

**Радиусы.** Карточки `rounded-xl` (12px), элементы управления `rounded-lg` (8px), плашки-теги
`rounded` (4px), точки и полосы `rounded-full`. Третьего радиуса нет.

**Отступы.** Страница `px-8 py-7`. Карточка `p-5`, плотная карточка `p-4`, плашка измерения
`p-3.5`. Между секциями 24px, внутри секции 8–12px. Сетка карточек `gap-4`, сетка измерений
`gap-3`.

**Никогда:** градиентных заливок на площадях, стекла/размытия, неона, свечения вокруг текста,
скруглений-«таблеток» у кнопок, двух рамок вокруг одного содержимого.

## 5. Каркас экрана

```
┌──────┬───────────────────────────────────────────────────────────┐
│ рейл │  ЗАГОЛОВОК ЭКРАНА                          [ ⊕ Действие ]  │
│ 64px │  подзаголовок — что здесь и сколько чего                  │
│      ├───────────────────────────────────────────────────────────┤
│  ▤   │  СТРОКА «СЕЙЧАС» — то, что меняется в течение часа        │
│  ₽   ├──────────────────┬────────────────────────────────────────┤
│  ↻   │  СПИСОК 300–350px│  ДОСЬЕ ВЫБРАННОГО                      │
│  ◈   │  сгруппирован    │  факты · измерения · таблицы           │
│  ⚙   │  по смыслу       │                                        │
└──────┴──────────────────┴────────────────────────────────────────┘
```

Два образца компоновки, третьего заводить не надо:

- **Список + досье** (ИИ, Финансы, Парк) — когда записей много и у каждой есть внутренность.
- **Полотно карточек** (Подписки, Дашборд) — когда записи равнозначны и внутренности почти нет.

Порядок сверху вниз всегда один: **что меняется сейчас → что требует внимания → инвентарь →
подробности**. Плата за месяц не может стоять выше строки лимита: первая меняется раз в месяц,
вторая — в течение часа.

## 6. Готовые компоненты

Брать эти, новых не плодить (`components/ui/Page.tsx`):

- `<Page>` — обёртка экрана с прокруткой и отступами.
- `<PageHeader title subtitle action>` — заголовок, подзаголовок, кнопка справа.
- `<Card className>` — `rounded-xl border border-border bg-card/60 p-5`.
- `<StatTile label value hint>` — **только когда число действительно одно на экран.** Четыре
  плитки в ряд — это шаблон дашборда, владелец его отверг.
- `<SourceBadge kind>` — откуда данные: `live` (янтарь) · `manual` (серый) · `soon` (амбер).
- `<Hint>` — вопросительный знак с пояснением, для того, что нельзя объяснить одним словом.
- `<Donut>`, `<Sparkline>` — только когда доля или динамика и правда несут смысл.

## 7. Ярлыки и что они значат

**Статус сущности** — цвет ПЛЮС форма плюс слово, никогда один цвет:

| Состояние | Знак | Цвет |
|---|---|---|
| работает | ● | `emerald #10b981` |
| хуже нормы | ▲ | `amber #fbbf24` |
| перезагружается | ◔ | `sky #38bdf8` (единственный пульсирует) |
| не отвечает | ■ | `rose #f43f5e` |
| не знаю | ◇ | `stone` |
| обслуживание | ⏸ | `violet` |

**«Не знаю» никогда не красится зелёным.** Отсутствие данных — это не «всё хорошо».

**Статус никогда не янтарный.** Янтарь занят акцентом; если статус будет ember, они сольются.

## 8. Честность данных — главное правило системы

Argus показывает не только цифры, но и **насколько этим цифрам можно верить**. Это его смысл, и
дизайн обязан это нести. Пять состояний, у каждого свой вид:

| Состояние | Как выглядит |
|---|---|
| **Измерено** — сказал сам провайдер | сплошная янтарная полоса, процент без оговорок |
| **Оценка** — посчитано по своим логам | полоса вполсилы, знак `≈` приклеен к числу, подпись «наблюдаемый максимум» |
| **Только время** — потолка нет вовсе | штриховка 135°, процента НЕТ, показываем абсолют |
| **Устарело** — измеряли давно | подпись «обновлено N дн. назад» янтарным |
| **Не знаем** — не спрашивали | пустое место и приглашение действовать, НИКОГДА не ноль |

Три запрета, каждый оплачен ошибкой на живом экране:

1. **Ноль ≠ неизвестно.** Ноль в денежной колонке читается как «пусто» и молча выпадает из
   итогов. Неизвестное пишется словами.
2. **Оценка обязана выглядеть оценкой.** Убери `≈` — и догадка станет неотличима от измерения.
3. **Два ответа на один вопрос рядом — ошибка.** Если провайдер назвал долю за период, своя
   оценка за тот же период не показывается вовсе.

## 9. Слова

Русский, обычный, без маркетинга. Пишем со стороны человека, а не системы: он «продлевает
подписку», а не «управляет биллинг-циклом».

- Кнопка называет действие: «Войти в кабинет», не «Отправить».
- Одно действие — одно имя во всём потоке.
- Ошибка объясняет, что случилось и что сделать, и не извиняется: «Сессия истекла — войдите
  заново», а не «Что-то пошло не так».
- Пустой экран — приглашение: «Ключ не заведён» плюс что это даст.
- Служебных пояснений про механику не пишем вовсе: «список обновляется при запуске», «пароли
  подтягиваются из браузера» — это рассказ о себе, а не помощь. Работающая норма молчит.
- Числа: деньги в родной валюте, сводный итог в USD, курс помечен приблизительным.

## 10. Движение

Переходы на наведении и смене статуса — 150–200 мс. Пульсирует ровно одно: «перезагружается».
Сцен при загрузке страницы нет. `prefers-reduced-motion` уважается везде, где есть анимация.

## 11. Проверка перед сдачей

- [ ] Янтарного не больше четырёх пятен, и все — CTA, навигация, ссылка, прогресс
- [ ] Ни один статус не покрашен в акцент; «работает» — emerald
- [ ] `tabular-nums` на всех числах
- [ ] Каждое число отвечает, откуда оно взялось (§8)
- [ ] Нет вложенных рамок и второй тени
- [ ] Айбрау-капсом не больше трёх на экран
- [ ] Нет текста про механику приложения
- [ ] Заголовки `white` на `#121110` дают контраст ≥ 4.5:1
- [ ] Экран отвечает на свой вопрос за три секунды без прокрутки

## Как этим пользоваться

Скопировать целиком и добавить одну строку:

> «Спроектируй экран **‹название›** для Argus по системе выше. Он отвечает на вопрос
> ‹один вопрос›. Данные: ‹список полей и откуда каждое берётся›. Компоновка: ‹список+досье |
> полотно карточек›.»

Всё, что не описано здесь, решается по духу §1: тихий пост наблюдения, куда заходят на двадцать
секунд свериться.
