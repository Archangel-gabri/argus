## §1. Механика «?» — что есть и чего не хватает

### Что уже есть
`src/renderer/src/components/DeviceDialog.tsx:79-107` — компонент `Field`:

```
Field({ label, hint?, full?, children })
```

Рендерит строку подписи, а справа — кружок 16×16 с символом «?»: `title={hint}`,
`aria-label={hint}`, `cursor-help`, `ring-1 ring-border`, ховер `text-slate-300`.
Используется 21 раз внутри диалога устройства.

### Чего не хватает
1. **Это нативный `title`, а не компонент.** Задержка ~1 с, оформление рисует ОС (белая плашка,
   системный шрифт) — мимо палитры Graphite & Ember; переносы строк не контролируются; на
   тач-экране не показывается; клавиатурой не открывается.
2. **Живёт внутри `DeviceDialog` и наружу не переиспользуется.** В `components/ui/` тултипа нет
   вообще — там только `Donut.tsx`, `Page.tsx`, `Sparkline.tsx`.
3. Ещё **24** места используют `title=` кустарно как тултип: `ScreenWindow.tsx:38,381,385,388,391,394,401`,
   `OverviewPane.tsx:210,234,361,455,459,513,543`, `ForwardsPane.tsx:109,144,175,183,235`,
   `FilesPane.tsx:142,148,191,195`, `MetricsPane.tsx:74,95`, `ScreenPane.tsx:16`,
   `ServerCard.tsx:175`, `DeviceDialog.tsx:96,128,141,153,485,599`.

### Вывод: компонент надо создать
**Создать `src/renderer/src/components/ui/Hint.tsx`.** Предлагаемый API:

```tsx
<Hint>Длинный текст объяснения</Hint>          // кружок «?» + попап
<Hint side="left">…</Hint>                      // сторона раскрытия
```

Требования, вытекающие из проекта:
- Попап: `bg-surface` · `border border-border` · `rounded-lg` · `text-[11px] leading-relaxed`
  `text-slate-300` · `max-w-[260px]` · `shadow-xl` — те же токены, что у меню карточки
  (`ServerCard.tsx:199`).
- `z-[70]`: выше drawer (`z-50`) и палитры (`z-[60]`), иначе тултип в drawer уедет под подложку.
- Открывается по ховеру **и по фокусу** (`Tab`), `role="tooltip"` + `aria-describedby`.
- Без анимации при `prefers-reduced-motion` — `DESIGN.md §5`.
- Кружок «?» — ровно тот, что уже есть в `Field` (`h-4 w-4`, `ring-1 ring-border`), чтобы
  диалог устройства не переехал визуально.

**Куда встаёт:**
- `DeviceDialog.tsx:94-102` — `Field` внутри себя меняет `title` на `<Hint>`; все 21 подсказка
  начинают работать нормально, ничего не переписывая на местах вызова.
- Рядом с заголовками панелей (там, где сейчас абзац снизу): `ScreenPane.tsx:126`
  («Агент трансляции»), `ForwardsPane.tsx:195` («Ручной туннель»), `OverviewPane.tsx:343`
  («Питание») и `:230` («Питание и ОС»), `DeviceDialog.tsx:398` («Заполнить по тексту»),
  `BanksView.tsx:30` («Добавить кошелёк»), `SettingsView.tsx:120` («Смена мастер-пароля»).
