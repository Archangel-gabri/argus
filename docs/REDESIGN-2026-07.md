# Argus (ex-Nexus One) — Redesign Spec 2026-07-11

> Утверждённый дизайн-спек полного редизайна: новая идентичность + визуальная система +
> переработка IA + новые фичи (банк-сессии, авторизация сервисов, персональные девайсы).
> Дополняет: `SPEC.md` (7 залоченных раундов — остаются в силе), `MASTER-PLAN.md` (видение),
> `UX-MAP.md` (карта UI «как есть» до редизайна).
> Утверждено владельцем в интерактивной сессии 2026-07-11 (подход B + все разделы + выбор
> концептов картинками).

## 0. Залоченные решения этой сессии

| Решение | Выбор владельца |
|---|---|
| Имя | **Argus** (стоглазый страж; ex-Nexus One) |
| Логотип | **Башня** (`argus-logo-tower-ember.png`) = иконка приложения/трея; **wordmark глаз+ARGUS** (`argus-wordmark-ember.png`) = сайдбар, lock-экран |
| Цветовой концепт | **C2 «Graphite & Ember»** (`concept-c2-graphite-ember.png`) — тёплый графит + янтарь |
| Стиль иллюстраций | **Изометрический tech-art** (30°, тёмный пьедестал, ember-свечение) |
| Банковские балансы | **Веб-сессии банков** (webview + парсинг ЛК); PDF-выписки остаются вторичным точным источником (SPEC р.5) |
| Подход | **B — полный редизайн** (identity + IA + иллюстрации), архитектура main-процесса и инварианты безопасности не трогаются |

Отклонено: концепты C1 (cyan, слишком плотно/геймерски) и C3 (violet); лого «orbital»
(похоже на React); имена Bastion/Helm/Atlas/Keep/Orbit/PULT.

## 1. Идентичность

- **Имя:** Argus. В UI — везде (тайтл окна, sidebar, lock-экран, палитра, `productName`
  в `package.json`, About). Папка `projects/Nexus-One/` НЕ переименовывается в этом этапе
  (отдельный шаг позже, чтобы не ломать реестр/скрипты вольта).
- **Иконка приложения/трея:** башня из серверных юнитов с глазом-линзой (ember). Исходник —
  `assets/concepts/argus-logo-tower-ember.png`; продовые размеры (512/256/128/48/32) нарезаются
  на этапе реализации.
- **Wordmark:** глаз в орбите + «ARGUS» белым техно-гротеском — сайдбар (компакт: только глаз
  + текст рядом), lock-экран (полный локап).
- Тон бренда: «спокойный страж» — не неон, не милитари; тёплый, дорогой, тихий.

## 2. Визуальная система «Graphite & Ember»

### 2.1 Токены (заменяют текущие в `main.css @theme` + `design/tokens.json` + `DESIGN.md`)

| token | value | роль |
|---|---|---|
| bg | `#121110` | фон приложения (тёплый почти-чёрный) |
| surface | `#1a1816` | sidebar / рейлы / плашки |
| card | `#201d1a` | карточки |
| card-hover | `#262220` | ховер |
| border | `#2a2622` | hairline-границы |
| accent | `#f59e0b` | ember-янтарь: CTA, активная навигация, ссылки (статус-кольца красятся цветом СТАТУСА, §2.2) |
| accent-hover | `#d97706` | ховер акцента |
| glow | `rgba(245,158,11,.14)` | свечение пьедесталов иллюстраций и hover-подсветка |
| text-hi | `#f5f2ee` | заголовки (тёплый белый) |
| text | `#a8a29e` | body (stone-400) |
| text-dim | `#78716c` | лейблы (stone-500) |

Типографика: Inter Variable остаётся; моно — для ip/путей/терминала. `tabular-nums` на всех
числах (инвариант). Радиусы: карточки `rounded-xl`, контролы `rounded-lg`. Тени: hairline +
мягкое ember-свечение ТОЛЬКО у активных/online элементов.

### 2.2 Статусы (6 состояний остаются, семантика цвета отвязана от бренда)

Цвет + форма + текст (colorblind-safe, инвариант из MASTER-PLAN C1):
online ● emerald `#10b981` · degraded ▲ amber `#fbbf24` (отличается от accent формой ▲ и подписью) ·
offline ■ rose `#f43f5e` · rebooting ◔ sky `#38bdf8` (единственный пульсирует) ·
unknown ◇ stone-серый · maintenance ⏸ violet. Никогда не «врать зелёным»: нет данных → unknown.

### 2.3 Иллюстрационный слой (новое ядро визуалки)

- **Каждая сущность получает изо-портрет**: единый ракурс 30°, тёмный скруглённый пьедестал,
  ember-подсветка, фон прозрачный/`bg`. Генерация: `tools/scripts/gen-image.sh --via openrouter`
  (фолбэк `--via vsegpt`; крайний — веб-Gemini через Brave CDP).
- **Style-lock промпт** (префикс каждой генерации): «isometric 3D illustration, 30-degree angle,
  matte dark graphite materials, standing on a dark rounded pedestal with a warm ember glow ring,
  subtle amber accent lights #f59e0b, very dark warm background #121110, soft studio lighting,
  premium tech-art, consistent style, no text».
- **Санкционированные сюжеты:** серверы — мини-стойки (вариации по роли: master/cascade/exit/db);
  личные девайсы — точные силуэты моделей владельца (Galaxy S8, Galaxy Buds, Vivobook S16,
  ПК-башня Castiel c RTX, DualSense, D-Link DIR-825, МТС Innbox); паспорт-девайсы (часы, iPhone) —
  те же правила.
- **Хранение:** `src/renderer/src/assets/illustrations/<slug>.png` (бандлится Vite);
  концепты/исходники — `assets/concepts/`. Дефолтный портрет на класс сущности, кастомный —
  переопределение per-device.

### 2.4 Мотив и мотус

Мотив: «тихий пост наблюдения» — просторно, тепло, ≤5 сигналов на карточку, прогрессивное
раскрытие (всё богатство — в детальном виде). Motion: transitions на hover/статусах; пульс —
только rebooting; никаких page-сцен. Reduce-motion уважается.

## 3. Информационная архитектура

Сайдбар: **Dashboard · Fleet · Finance · Subscriptions · AI · Settings** (`useUI.view` остаётся
единственным источником экрана; Streaming как вкладка УДАЛЯЕТСЯ).

| Было | Стало |
|---|---|
| Devices | **Fleet** с тремя группами-фильтрами: *Servers* / *Personal* / *Network* |
| Banks | **Finance** (банк-сессии + крипто + T-Invest + ручное) |
| Streaming (вкладка-заглушка) | грань **«Screen»** в детальном виде устройства |
| — | **Settings** (новый экран, v1-подмножество из MASTER-PLAN C8) |
| AI Accounts (мок) | **AI** — живой UI на уже готовом `ai:*` IPC |

- **Детальный вид устройства** — правый drawer-оверлей (через `useUI`-флаг, инвариант §10
  UX-MAP): табы-грани Overview / Terminal / Files / Forwards / Metrics / Screen / Billing /
  Passport. Существующие оверлеи (Terminal/SFTP/Forwards) становятся табами drawer'а, их IPC
  не меняется.
- **Карточка ПК (dual-boot):** кнопки **→ Linux / → Windows / Sleep / Wake** прямо на карточке —
  UI-обёртка над уже работающей механикой владельца (Tailscale + WoL + grub-reboot по SSH,
  см. память `sys-pc-remote-control`). Подтверждение перед reboot-действиями.
- **Паспорт-карточки:** девайс без подключения (часы, iPhone, наушники…) живёт во Fleet:
  модель, изо-портрет, какие API доступны, заметки; батарея — если достаёт (BlueZ/HA).
- **ИИ-заполнение форм:** в Add-диалоге поле «вставь что угодно» (конфиг, письмо хостера,
  ссылка) → локальная Ollama парсит в поля формы (превью перед записью). Облачная модель —
  только по явному выбору в Settings.
- **Глобальный поиск** в сайдбаре ищет по всем разделам (сейчас — только Devices); результаты
  сгруппированы по граням, Enter = primary-действие (как в палитре).
- **Мёртвые контролы выпиливаются:** Quick Connect (рейл), Group settings (шапка). Шестерёнка
  профиля ведёт в Settings.

### 3.1 Анатомия карточки сервера v2 (по концепту C2)

Сверху вниз: бейдж хостера (чип, top-right) → изо-портрет на пьедестале по центру,
**кольцо-свечение вокруг = статус** → **кружок-флаг страны** (bottom-left портрета) →
имя + `user@ip` (моно) → компактные CPU/RAM-бары со значениями → две кнопки: **SSH**
(filled ember) + **Panel** (outline, консоль хостера) → цена/ренивал-чип (грань подписки).
Меню ⋮ (Edit / Files / Forwards / Delete) остаётся. Спарклайн CPU-истории — в детальном
виде (Metrics), НЕ на карточке (минимализм: ≤5 сигналов).

### 3.2 Dashboard (live-агрегатор)

Плитки Net worth и AI переключаются с моков на живые сторы (кошельки + `api.ai.list()`).
Секции-сводки по граням: флот (roll-up = худший ребёнок), деньги, ренивалы ближайших 14 дней,
ИИ-траты. Guided empty-states с CTA (из MASTER-PLAN C0.7).

## 4. Finance: банк-сессии (выбор владельца)

- **Сущность BankSession:** банк, изолированный Chromium-partition (`persist:bank-<id>`),
  статус сессии (active / expired / needs-reauth), lastSync, баланс (только сумма + валюта).
- **Флоу:** «Добавить банк» → каталог (Сбер, Т-Банк, Альфа, ВТБ…) → открывается отдельное
  окно логина (видимое, обычный веб-ЛК) → после входа приложение сохраняет сессию partition'а
  и закрывает окно.
- **Синк баланса:** по кнопке/интервалу main открывает **скрытое** окно того же partition,
  выполняет «рецепт» банка (файл: url + селекторы/regex → баланс), пишет в vault только
  `{balance, currency, ts}`. Рецепты лежат отдельно от кода (`bank-recipes/*.json`) и
  обновляются точечно при смене вёрстки.
- **Карточка банка:** лого, баланс, «синхронизировано N мин назад», индикатор здоровья сессии,
  кнопки «Обновить» / «Открыть ЛК» (видимое окно) / «Переавторизоваться».
- **Безопасность (честно в UI через LimitNote):** cookies живут в Chromium-partition на диске
  (OSCrypt/KWallet-шифрование Chromium), метаданные и балансы — в SQLCipher-vault; step-up
  подтверждение перед открытием ЛК и перед удалением; анти-бот/смена вёрстки → рецепт чинится,
  сессия может протухать — приложение показывает это, а не молчит.
- Остальные источники Finance без изменений: крипто-RPC (live), T-Invest (SPEC р.4),
  PDF-выписки через Python-сайдкар (SPEC р.5), ручные холдинги (перевести с мока на vault-CRUD).

## 5. Subscriptions

- **Авторизация сервисов** тем же webview-механизмом (partition `persist:svc-<id>`):
  Netflix/Spotify/Yandex Plus/… → рецепт тянет «активна до, цена, статус оплаты».
- Статусы подписки: active / **unpaid** (красный бейдж) / expiring (≤14 дн, жёлтый) / cancelled.
- **Календарь ренивалов** на месяц + алерт «цена выросла» (сравнение с прошлым значением).
- Залоченное остаётся: Gmail/IMAP-квитанции (SPEC р.5), инфра-косты серверов live, ручной CRUD.

## 6. AI, Settings, Онбординг

- **AI:** подключить готовый бэкенд (`api.ai.list/create/check/remove`) к UI: карточки
  провайдеров живые, форма добавления ключа, кнопка проверки, live-кредит OpenRouter,
  бейдж сайдбара = реальное число. График spend — Phase 3+.
- **Settings v1** (подмножество C8): Appearance (акцент, плотность, reduce-motion) ·
  Security (авто-лок, очистка буфера, смена мастер-пароля, regenerate Recovery Kit) ·
  Data (export/import `.nxs`) · Integrations (Ollama URL, ключи ИИ) · About. Остальные
  разделы дерева — по мере фич.
- **Онбординг:** welcome → создание vault → **zxcvbn-метр** (гейт по скору) → **обязательный
  Recovery Kit** (без сохранения не пройти — SPEC р.7) → импорты (ssh_config превью,
  Tailscale) → dashboard с guided empty-states + coach-mark ⌘K.

## 7. Инварианты (не ломать — §10 UX-MAP)

1. Секреты только в main; renderer видит DTO без секретов.
2. `useUI.view` — единственный роутинг; оверлеи — через `useUI`-флаги из `App.tsx`.
3. `LimitNote`-честность на вкладках с ограничениями — сохраняется и расширяется (банк-сессии).
4. Поллинг метрик 90с + `metrics.history` контракт.
5. `tabular-nums`; деньги в родной валюте, тоталы в USD (SPEC р.4).
6. Ров «один объект — много граней»: детальный drawer = грани одного объекта, таблица `links`.

## 8. Этапы реализации

- **B1 — Identity + reskin:** имя Argus (UI/`productName`/тайтл), нарезка иконки, wordmark в
  сайдбар/lock, новые токены (§2.1), статус-цвета (§2.2), выпил мёртвых контролов. Приложение
  полностью функционально на каждом шаге.
- **B2 — Карточка v2 + иллюстрации:** генерация базового сета изо-портретов (5 серверов +
  дефолты классов), новая анатомия карточки (§3.1), детальный drawer с гранями (перенос
  Terminal/SFTP/Forwards в табы).
- **B3 — IA:** Fleet-группы (Servers/Personal/Network), паспорт-карточки, Settings v1,
  AI живой, Dashboard live, онбординг + Recovery Kit, глобальный поиск.
- **C — фичи:** банк-сессии (§4), авторизация сервисов (§5), KDE Connect / Buds / OS-switcher
  ПК, Screen-грань (scrcpy/noVNC), ИИ-заполнение форм (Ollama).
- Каждый этап: `npm run typecheck` + `electron-vite build` зелёные; скриншот + visual-QA
  против концепта C2; UX-MAP и DESIGN.md обновляются по факту.

## 9. Риски и не-цели

- **Анти-бот/вёрстка банков** — рецепты хрупкие by design; UX честно показывает протухание.
  Не-цель: headless-обход защит, автоплатежи, любые write-операции в банках — только чтение баланса.
- **Сессии банков на диске** — компромисс v1 (Chromium OSCrypt + шифр-vault для метаданных);
  полный in-vault перенос cookies — исследование в Phase C.
- Изо-портреты — генеративные: консистентность держим style-lock промптом и edit-режимом;
  при дрейфе стиля — перегенерация от эталона.
- Не-цели этапа: topology-canvas (отклонён SPEC р.7), переименование папки проекта,
  облачный синк, мобильная версия.
